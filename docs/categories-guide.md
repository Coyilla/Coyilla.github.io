# 分类结构
设 5 个大类，每个大类下再细分标签：
## 1. 技术（Tech）
- 编程语言：Go / Python / JavaScript
- 工具链：Git / Docker / Linux / VSCode
- AI 探索：Qwen / 本地部署 / Prompt 技巧
- 踩坑记录：报错解决 / 环境配置 / 性能优化
## 2. 个人成长（Growth）
学习方法：如何学一门新技术 / 读书笔记
思考复盘：近期感悟 / 认知升级
效率工具：时间管理 / 笔记系统 / 习惯养成
## 3. 随笔故事（Stories）
小故事：以前写的短篇 / 虚构创作
生活片段：校园 / 旅行 / 日常观察
## 4. 周报（Weekly）
每周总结：本周做了什么 / 学了什么 / 下周计划
## 5. 关于我（About）
个人介绍：我是谁 / 我在做什么 / 联系方式
