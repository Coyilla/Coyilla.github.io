GitHub Copilot 使用指南

GitHub Copilot 使用指南 适用环境：VS Code / Visual Studio / JetBrains IDE / Xcode / GitHub Web / CLI 核心形态：Inline Completion（补全） + Inline Chat（行内对话） + Copilot Chat（侧边栏对话） + Edit Mode（多文件编辑） + Agent Mode（自主代理） + Cloud Coding Agent（云端建 PR） 1. 先建立心智模型 GitHub Copilot 不是“一个聊天框”，而是一套分层能力： 层级 名字 你在干嘛 Copilot 在干嘛 L0 Autocomplete 写代码 在光标处补下一行/下一段 L1 Inline Chat 选中代码改代码 在当前文件里做定向修改 L2 Copilot Chat 问项目/问报错/问架构 读上下文，给解释、代码、命令 L3 Edit Mode 改几个文件 按你给的范围做受控编辑 L4 Agent Mode 给目标，不管步骤 自己读文件、跑命令、修错、迭代 L5 Coding Agent 给 issue / PR 描述 云端开分支、改代码、跑测试、提 PR 一句话总结： ...
