个人博客搭建记录

开始 这篇文章记录一下我搭建博客时踩过的坑… 1. 为什么选 Hugo和PaperMod 主题 因为我想要一个轻量级、快速、易于部署的博客系统。Hugo 是一个静态网站生成器，它可以将 Markdown 文件转换为 HTML 页面，生成的页面可以直接部署到 GitHub Pages 上，非常适合个人博客。 PaperMod 是一个简洁、现代的 Hugo 主题，支持暗黑模式、响应式设计、代码高亮等功能，非常适合技术博客。它的配置也比较简单。 2. 部署到 GitHub Pages 我选择将博客部署到 GitHub Pages，这样可以免费托管我的博客，并且可以通过 GitHub Actions 实现自动部署。每次我提交新的文章，GitHub Actions 会自动构建并部署我的博客，非常方便。 3. 遇到的问题 文件图片的链接到底能不能用中文？ 有时候图片文件名中有中文时，图片就无法加载。但是很多截图、微信图片文件，图片文件名都会有中文。这个就很麻烦。 但是有时候这个问题又不会出现，很奇怪。 4. 搭建记录 2026-10-14 开始搭建 这一天，我闲着无聊，开始写CANN训练营的技术文章。既然文章都写好了，就萌生了一个想法：为什么不自己搭建一个博客，把这些文章都放上去呢？于是，我开始了我的博客搭建之旅。 这个想法已经在我脑海里盘旋了很久，2026年10月，终于开始了。 主要完成任务： 搭建博客基础雏形，采用Hogo+PaperMod，完成带主页+目录的博客，成功部署到github上并准备好了域名 发表4篇文章作为试水 添加了bing的站点，现在bing上已经可以搜到博客了 发现别人的博客好好看…我也想要…慢慢做吧 起了个好听的名字：Coyilla的技术随想录 在想一些不那么技术的事：把binggo之争放上来 附一张最初的博客，希望以后能坚持更新，改头换面 2026-10-15 发现用markdown做有关图片的插入操作太麻烦了，需要事先将图片复制到文件夹下，再写图片文件地址。所有加了一个插件：Paste image。终于可以在md中自由插入图片了。 加了categories和tags 2026-10-15 更改了post文件夹下文件的管理方式，改成这样： content/posts/ ├── tech/ │ ├── 2026-10-hugo-blog-setup.md │ └── 2026-10-git-commands.md ├── growth/ │ └── 2026-10-learning-method.md └── weekly/ └── 2026-10-weekly.md
