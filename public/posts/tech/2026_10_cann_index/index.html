day1上午 CANN基础#

PART1 人工智能基础#

人工智能起源#

  • 图灵测试 图灵
  • 达特茅斯会议 麦卡锡

人工智能发展#

从“感知理解世界”向“生成创造世界”扩展

  • 上世纪 达特茅斯会议
  • 1997 深蓝机器人战胜人类
  • 2015 视觉识别超过人类
  • 2020 蛋白质检查
  • 2023 chatgpt出现

概念理解：人工智能、机器学习和深度学习#

人工智能核心三要素：数据+算法+算力#

  • 算力：身体
  • 算法：大脑
  • 数据：粮食

算法理论基础：业务抽象成数据模型的表达式#

建模-训练-微调-推理

神经网络算法的发明是现代人工智能的开端#

模拟神经元
权重-激活-状态
基于向前传播和向后传播的神经网络开启了现代AI的大发展

神经网络——2012年ImageNet取得巨大突破，被往返认为现代AI的开始#

海量数据+神经网络算法+大算力=现代AI

概念理解：训练和推理#

  • 开发态-AI训练：通过大量数据学习“规则”形成模型/算法
  • 部署态-AI推理：利用已经训练好的“规则”完成具体任务

从算法为中心到以数据为中心，是AI大模型所带来的重大范式转移#

AI=Code+Data
数据的质量，决定了算法性能的上限。

人工智能概念：计算图、算子#

计算图本质上是一个有向图，由节点（Node）和边（Edge）组成
子（Operator，简称 Op）是计算图中的基本计算单元

算子#

  • 算子名称
  • 算子裂隙
  • 数据容器：张量

张量#

Tensor是存储算子输入数据与输出数据的容器

  • 名称 name
  • 形状 shape
  • 数据类型 dtype
  • 数据排布格式 format：4D格式

小结#

AI模型=计算图=算子组合->

PART2 什么是NPU#

为什么要NPU#

  1. 计算密集。计算任务大，操作逻辑简单
  2. 数据并行。操作独立，可同时处理
  3. 低精度可接受。AI对计算误差有较高容忍度。使用半精度或整数即可获得足够好的结果

昇腾NPU：AI计算的发动机#

华为昇腾AI芯片，采用达芬奇架构，集成超大规模的计算单元，是支撑AI全场景应用的核心硬件基础

CPU vs NPU：算力差距有多大#

16*16矩阵：

  • CPU: 16 * 16 * 16 * 2
  • Vector：16 * 16
  • Cude：1

异构计算：让专业硬件干专业的事#

  • cpu：系统的指挥中心
  • npu：ai的超级工人和专职计算手

Host与Device#

硬件产品介绍#

昇腾AI处理器系列

昇腾AI处理器抽象硬件架构#

每个AI处理器包含多个AI Core，AI Core包含：

  • 计算单元：标量计算单元，向量计算单元，矩阵计算单元
  • 存储单元：Global Memory，Local Memory
  • 搬运单元：DMA

AIcore内部并行架构抽象#

  • 异步指令流
  • 同步信号流
  • 计算数据流

多核并行#

单张NPU集成多个AI Core，通过任务拆解，让多个计算核心并行工作 算子计算时：

  1. Tiling数据拆分
  2. 多核并行计算
  3. 隐式同步

PART3 什么是CANN#

CANN:对上适配AI框架，对下驱动NPU硬件#

CANN助力构建昇腾AI算力平台#

架构：

  • 运行时层（底层）：运行时，驱动
  • 编程与编译（中间层）：算子编程，毕昇编译器
  • 加速库（上层）：算子库（Ops-nn,ops-math），通信库（hixl,shmem,hccl），领域加速库（sip），图引擎（ge,metadef,graph-autofusion）

组件详解1-框架适配层：无缝对接AI昇腾#

目标是实现上层AI架构与昇腾NPU的无缝融合

组件详解2-加速库之算子库：AI计算的“标准件仓库”#

  1. ops-math
  2. ops-nn
  3. ops-cv
  4. ops-transformer
  5. 支持自定义算法扩展

组件详解3-加速库之通信库：多卡协同#

  • HCCL集合通信
  • HIXL单边通信

组件详解4-加速库之图引擎GE：全局优化的智慧大脑#

  1. 图编译：通过算子融合减少通信开销，自动编译算子执行顺序形成流水线
  2. 图执行：算子图下沉

组件详解5-加速库之领域加速库#

组件详解6-编译与编程：Ascend C#

构建多层级API，支撑多维场景算子开发诉求

  • 语言扩展层C
  • C++（Tensor API,基础API，高阶API，Ascend）
  • PyAsc

组件详解7-编译器、运行时与驱动#

  • 毕昇编译器
  • 运行时
  • 驱动

实战演练#

  1. 框架适配（torch_npu）
  2. 算子映射与图捕捉
  3. 编译优化（GE+毕昇）
  4. 硬件执行与结果就绪

Transformer架构#

分词，词向量，自注意力，注意力机制，Softmax，多头注意力机制，前馈神经网络，Add&Norm，输出层

大语言模型核心架构演进#

  • DenseNetwork
  • MoE
  • MLA
  • DSA
  • GatedDeltaNet
  • DiT
  • Hybrid Model

DenseNetwork:Llama#

优化点：rmsnorm，SwiGLu，GQA

MoE#

用一组系数激活的专家网络替换了传统Transformer中的密集FFN层。

MLA#

对key和value做压缩，减少缓存占用，同时尽量不影响推理能力

DSA#

闪电索引+Top-k稀疏筛选

GatedDeltaNet#

融合门控机制+Delta更新规则的线性注意力变体架构
