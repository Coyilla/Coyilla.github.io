开始#

这篇文章记录一下我搭建博客时踩过的坑…

1. 为什么选 Hugo和PaperMod 主题#

因为我想要一个轻量级、快速、易于部署的博客系统。Hugo 是一个静态网站生成器，它可以将 Markdown 文件转换为 HTML 页面，生成的页面可以直接部署到 GitHub Pages 上，非常适合个人博客。

PaperMod 是一个简洁、现代的 Hugo 主题，支持暗黑模式、响应式设计、代码高亮等功能，非常适合技术博客。它的配置也比较简单。

2. 部署到 GitHub Pages#

我选择将博客部署到 GitHub Pages，这样可以免费托管我的博客，并且可以通过 GitHub Actions 实现自动部署。每次我提交新的文章，GitHub Actions 会自动构建并部署我的博客，非常方便。

3. 遇到的问题#

文件图片的链接到底能不能用中文？#

有时候图片文件名中有中文时，图片就无法加载。但是很多截图、微信图片文件，图片文件名都会有中文。这个就很麻烦。

但是有时候这个问题又不会出现，很奇怪。
